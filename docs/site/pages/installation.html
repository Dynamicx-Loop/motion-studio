Getting started / Motion Studio

Installation

Independent tools, one place to keep setup and experiment records.

Motion Studio does not yet have a single installable runtime. This guide describes the recorded Legion setup; a clean installation on another machine has not been verified.

Prerequisites

  • To read this bundle: a browser that opens local HTML files and the accompanying selected edition under outputs/docs-site/. No Python or server is needed for reading.
  • To rebuild documentation: Python 3 and the saved project sources and report artifacts. The builder uses only the standard library.
  • To use a motion tool later: its own environment, licensed model/robot assets and the required hardware. Keep external checkouts and environments independent.

Recorded Legion setup

The UMR setup record dated 22 October 2026 reports Python 3.12, PyTorch 2.7.1 / CUDA 12.8, an RTX 5070 Laptop GPU (8 GB), and an isolated environment under externals/UMR/.venv. Its validation covers imports, CUDA computations, SMPL-X forward passes and Astro MJCF loading. These are historical checks, not a fresh environment validation by this documentation task.

Model weights and the Astro robot assets use existing local paths with separate terms. ProtoMotions includes Git LFS pointers, so a source checkout alone does not establish that its media or runtime is usable.

UMR setup, prerequisites and recorded checks · ProtoMotions / PyRoki setup record · hhtools migration record

Inspect workspace registrations from the project root before setting up a tool:

python3 scripts/workspace.py list
python3 scripts/workspace.py check

These inspect registrations; they do not prove GPU jobs or licensed assets are ready. Installation and experiment commands in historical records are not part of this quick start.
