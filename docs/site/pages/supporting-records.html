07 / Keep it growing

Write a record. Add an entry. Rebuild.

Markdown and JSON are the sources of truth. Add a stable document ID, source path, title and evidence status to docs/site/catalog.json. Add significant decisions to its timeline with a source link. Keep old records intact. Choose an unused edition ID for every build; an existing output is refused.

python3 scripts/build_docs.py --edition local-20261029-03
python3 scripts/verify_docs.py --edition local-20261029-03

Double-click docs.html in the Motion Studio project root. The reading pages use ordinary relative file links; CSS, JavaScript, search text, diagrams and displayed figures are embedded. There is no redirect to localhost and no server, fetch, web font or service worker required for reading.

The first built-in-browser file-open check showed a blank page; the cause remains unresolved. Automation cannot access that view or navigate file URLs. The build validates static content, links and embedded data, and the guide records the remaining diagnostic. External citations remain optional online references.
