# Motion Studio local tracker

Specs, tickets, and investigation maps live here until an explicit tracker
migration. Follow [the tracker conventions](../docs/agents/issue-tracker.md) and
[triage statuses](../docs/agents/triage-labels.md).

Create one directory per effort, with `spec.md` or `map.md` and an `issues/`
directory containing one numbered Markdown file per ticket. No tickets have
been created as part of setup; add them as work is scoped.

These records can be committed to the root repository. Keep large artifacts in
`outputs/` and record paths and provenance in the ticket or experiment notes.
